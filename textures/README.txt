HAILSTORM TEXTURES
==================
Download each set from ambientCG (ambientcg.com), choose "1K-JPG", unzip,
and drop the files in THIS folder with their original names (flat, no subfolders).

Only these 3 files per set are needed (skip the rest to keep the repo small):
  <ID>_1K-JPG_Color.jpg
  <ID>_1K-JPG_NormalGL.jpg      (NormalGL, NOT NormalDX)
  <ID>_1K-JPG_Roughness.jpg

Sets:
  Grass001   main grass
  Grass004   grass variation
  Ground037  damp forest earth
  Ground110  dry dirt
  Ground106  mud
  Ground111  rubble / brick debris
  Gravel043  paths / trenches
  Snow015    dirty snow
  Snow014    clean snow
  Snow013    trampled snow
